수강신청 시간표

이름과 학교 이메일로 본인 확인 후 신청하거나 기존 시간표를 수정할 수 있습니다.

연결 설정이 필요합니다

Supabase 프로젝트를 만든 뒤 config.example.json을 config.json으로 복사하고 Project URL과 publishable key를 입력하세요. 미리보기는 주소 끝에 ?demo=1을 붙여 확인할 수 있습니다.

학교 이메일 로그인

이메일로 전송되는 확인 링크를 열면 로그인됩니다. 링크를 사용할 수 없는 환경에서는 인증번호 메일을 선택해 주세요.

저장된 신청을 불러왔습니다. 필요한 시간만 바꾸어 다시 저장하세요.

신청 현황

각 교시에서 한 수업을 선택합니다. 영화는 두 교시를 사용하며, 성경읽기와 마네도 지정된 교실 좌석을 사용합니다.

저장 전 규칙 확인
저장 시 좌석과 조건을 서버에서 다시 확인합니다.
시간표를 불러오는 중입니다.

학교 이메일 확인은 Supabase 이메일 인증을 사용합니다. 제출한 시간표는 이 계정에서 다시 열어 수정할 수 있습니다.
